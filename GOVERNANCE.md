# Project Governance

DriftTrust-Audit is currently maintained as a research prototype.

## Decision Principles

Changes should support at least one of the following:

- better research validity,
- stronger auditability,
- clearer ISO/security-governance mapping,
- more reproducible experiments,
- improved implementation quality,
- clearer professor-facing or reviewer-facing documentation.

## Research Claims

Claims in the repository should distinguish between:

- implemented and verified behavior,
- planned paper-grade extensions,
- hypotheses for future experiments,
- limitations caused by simulated data or local dependencies.

## Maintainer Responsibilities

Maintainers should review changes for research integrity, preserve reproducibility, keep README and citation metadata current, and avoid merging results that cannot be reproduced.
