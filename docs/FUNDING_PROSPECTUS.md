# Funding Prospectus

## Project Title

DriftTrust-Audit: Audit-Ready Adaptive Zero Trust Access Control Under Concept Drift

## Funding Rationale

Organizations increasingly use AI-supported security decisions, but adaptive
AI systems create accountability risk. If an access-control model changes after
drift, auditors need evidence explaining why the update occurred and whether it
remained policy-conformant.

DriftTrust-Audit addresses this by combining adaptive trust scoring with
audit-ready governance artifacts.

## Academic Fit

The project fits research groups in:

- cybersecurity,
- information security management,
- trustworthy AI,
- explainable AI,
- compliance automation,
- adaptive access control,
- Zero Trust Architecture.

## Research Questions

1. How can adaptive trust models explain and justify their own updates?
2. How can explanation consistency be measured across model adaptations?
3. How can adaptation evidence be mapped to security-management controls?
4. How does audit-ready adaptation compare with performance-only adaptation?

## Expected Outputs

- Open-source research prototype.
- Dataset simulator for concept-drifting access telemetry.
- Formal AJR schema.
- Explanation-Consistency Index.
- Evaluation framework and ablation studies.
- Journal or conference manuscript.
- PhD research proposal.

## Long-Term Impact

This work can support organizations that need adaptive AI security controls
without sacrificing auditability, compliance, and institutional trust.
