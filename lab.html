Upload a CSV with the 12 feature columns below. Optional label: 0 = benign, 1 = attack. Without labels, the system scores flows but does not invent training feedback.

Up to 256 records and 2 MB per upload. Labels are visitor assertions, not independently verified ground truth. Do not include credentials or personal information.

Required column names and input semantics
Packet and flag fields are counts; duration is seconds; packet rate is packets per second; payload statistics and initial TCP window sizes are bytes; down/up ratio is dimensionless. All values must be finite and non-negative. Arbitrary browser telemetry is not interchangeable with these measurements.

What this deployment does and does not establish
The server executes the same mathematical model and update code as the public-data experiments. It stores model state and audit records in a database, separate for every visitor. Single-flow inference is a network-risk estimate, not a permission decision. The experiment assumes timely labels; the lab accepts explicitly supplied labels or known dataset labels. Integration with enterprise identity providers, collectors, policy enforcement points, and trusted analyst feedback remains deployment work outside this research demo.
Fixed-reference gates may block useful learning about new attacks. Raw model scores are not calibrated security guarantees. Model and data versions are available on the research page.
