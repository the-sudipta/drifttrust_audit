# Security Policy

DriftTrust-Audit is a research prototype using simulated telemetry. It does not
require real network access and should not be connected directly to production
access-control systems.

## Supported Versions

The current research prototype is version `0.1.x`.

## Reporting Security Issues

Please report security issues privately to the project maintainer before public
disclosure.

Do not include real credentials, sensitive logs, internal network data, or
personally identifiable information in issues or pull requests.

## Data Safety

The repository is designed for synthetic data. If you adapt it for real logs:

- anonymize user and device identifiers,
- remove credentials and secrets,
- document data retention assumptions,
- comply with institutional ethics and data-governance requirements.
